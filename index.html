Web2File Privacy Policy

Last updated: October 2026

Overview

Web2File is a browser extension that allows users to save text they intentionally select on webpages directly to user-selected destination files.

Information Web2File Processes

Web2File processes webpage text selected by the user for the purpose of saving that content to the user's selected destination file.

When the user enables source information, Web2File may also process the current webpage title, URL, date, and time so that this information can be saved together with the selected text.

Local Storage

Web2File may store extension settings, destination information, licensing information, and pending save information locally in the user's browser as necessary to provide the extension's functionality.

Data Use

Web2File does not sell user data. User data is not used for advertising, creditworthiness, lending, or purposes unrelated to Web2File's core functionality.

Contact

For questions about this privacy policy or Web2File's privacy practices, please contact the Web2File publisher through the contact information provided on the Chrome Web Store listing.
